# `wanted.rs`

PURE reconcile-core (zero I/O): `reconcile_title` + lifecycle predicates (`wants`, `user_finished`, Trigger A `trigger_a_finished`, Trigger B `trigger_b_abandoned`; the private `removable` is the removal predicate `reconcile_title` applies, and the test-only `should_remove` wraps it; `abandoned_removable` is its Trigger B half (no manual provenance + `trigger_b_abandoned`), which `removable` reuses and `tasks::plan_reconcile_ops` applies to shows); types `TitleView`/`Owned`/`Action`.
`Owned` carries `owned_episodes` (every episode the group owns) and `covered_episodes` (those a present or `Pending` copy supplies): only covered episodes count as available, while a manual show restores a lapsed, watched episode from `owned_episodes`.
**Specials (`SPECIALS_SEASON` = 0) are outside the regular run** (`is_regular_episode`): `user_finished`'s "every aired episode watched" ignores season-0 aired entries and the Show acquire set never includes one — consistent with both sources it joins (TMDB's aired set already drops season 0 via `parse_season_numbers`; Trakt's watched history omits it and `show_progress` uses `specials=false`), so a fully-watched show is never blocked by a special Trakt never reports, and catch-up never chases one.
`monitor_episodes`' removal guard treats an aired set with no regular episode as empty.
A show Trakt reports the user behind on (`WatchedState::Show.trakt_behind`, set by `sync_trakt_user`'s `mark_trakt_behind` for every catch-up show in `behind`, including one assumed behind because `show_progress` failed or there was no Trakt id, and by `build_wanted` for every show in `/sync/playback`) is never finished (`user_finished` is false), so Trigger A needs TMDB and Trakt to agree.
With `REMOVE_FINISHED_SHOWS` off, a catch-up show is never finish-removed even when TMDB lacks an episode Trakt counts as aired
