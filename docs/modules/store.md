# `store.rs`

`Store` — owns all redb table definitions, schema **v8** + migration hook (v7→v8 flags `quality.unverified` on every owned record with a known `quality` that some `selection` entry serves from a non-MKV/MP4 file — e.g. an `.avi` — in one write transaction; idempotent, skipped for a fresh DB.
At migration time only engine-acquired copies had such an entry: an account-mirror record never got one — the VFS served it via the largest-file fallback (since then `selection::repoint_to_better_copies` can point a slot at a better mirror copy) — and `record_mirror_owned` never rewrites an existing record, so a mirror copy recorded before v8 in a non-MKV/MP4 file is **not** flagged retroactively; mirror copies recorded from v8 on are flagged at creation by `mirror_quality`), `open()` with auto-recovery (moves a genuinely-corrupt/unreadable DB aside and recreates it; an intact-but-unusable DB — newer schema or older redb format — instead fails startup), and typed async accessors for: `matches` cache, `owned_hashes`, `authoritative_ids`, `blacklist` (keyed by `(media_type, tmdb_id, hash)` — a movie and a show sharing a numeric TMDB id keep independent rejection histories, like every other table; TTL-pruned — `prune_blacklist_before` is called from the scan loop on startup + ~daily with a 30-day TTL so the otherwise append-only table can't grow unbounded; a rejected hash also becomes retryable again after the TTL), `trakt_tokens` + `wanted` (SP2; a show row's `WatchedState::Show.trakt_behind` records that Trakt reported the user behind on the show, or that the sync assumed so; a row written before the field existed reads as `true` (`legacy_trakt_behind`) until the next successful sync rewrites it), and (SP3) the `selection` table (slot → `{hash, file_path}`) and `upgrade_checks` cursor (rows of titles no longer owned are dropped with the blacklist prune, `prune_upgrade_checks_not_owned`), and the `staging` table of staging intents for upgrade candidates and acquisitions being added (lowercased hash → `StagingIntent { torrent_id, started_at }`, accessors `claim_staging_intent` (an exclusive claim: one write transaction that refuses with `Ok(false)` while an intent for the hash is open; a successful claim is noted in memory as this process's, `Store::local_staging_age`, before the commit, on the monotonic clock and never by wall-clock time, so a clock step can't make the staging sweep delete a staging still in flight) / `set_staging_torrent_id` / `clear_staging_intent` (drops only the note of the intent it removed, matched by a per-claim generation) / `all_staging_intents`; created by `ensure_schema` with no schema bump).
Also `has_matches`, `set_imdb_id_if_empty`, `forget_owned` (drops an owned record, its authoritative id and every `selection` slot whose entry still names the hash, matched inside one write transaction, so a slot a concurrent upgrade swap repointed meanwhile survives and a failure changes nothing; every production removal of an owned hash's records goes through it: dedup, `execute_remove`, the mirror's phantom reaper, its absent-record reaper (`reap_absent_mirror_owned`) and its drop of a record whose torrent lists no video file, `fail_and_reacquire`, `reap_lapsed_superseded`, and the upgrade prune and rollback (`upgrade::prune_owned_hash_in`, `upgrade::forget_deleted_copy`), while `remove_owned` is left only to undo a record whose authoritative write just failed), `set_provides_if_empty` (sets `provides` on a `Verified` show record whose `provides` is empty, in one transaction touching no other field; it never writes an empty set or a missing record, and returns whether it wrote), `replace_quality_if_eq` (replaces a `Verified` record's quality only while it still equals the expected value, in one transaction touching no other field; the quality backfill's compare-and-set), `served_episode_names` / `record_served_episode_names` (the episode naming the VFS last served, in the `meta` table), `create_selection_if_absent` (writes a `selection` slot only while it has no entry; the selection pass's slot for an episode no slot covers, beside its `repoint_selection_if`), `mark_verified_if_present` (marks an owned record `Verified`, with its `provides` and a cached quality carrying the `unverified` flag, in one transaction; it never writes back a missing record), `blacklist_newest_at_by_hash` (per hash, the newest blacklist `at` ignoring the given reasons; used by the mirror's phantom reaper), `replace_user_wanted_if_enrolled` (a sync writes a user's wanted rows in one transaction that first checks the token row exists) and `remove_trakt_account` (the token row and the user's wanted rows in one transaction).
`authoritative_ids` keys are lowercased like `owned_hashes`.
`OwnedRecord` carries the persisted `AcquireRequest` (incl. `original_language` and `spoken_languages: Option<Vec<String>>` — `#[serde(default)]`, `None` = never fetched: a pre-existing record or an account-mirror record, backfilled once by the upgrade pass via the atomic `backfill_title_languages_if_unset`, which fills only the unset language fields — `spoken_languages`, and `original_language` too when it is `None`, as on an account-mirror record), per-user `Provenance` and (SP3) `provides: Vec<(season, episode)>` — the episodes this hash supplies — and `quality: Option<QualitySummary>` — compact release snapshot for upgrade comparison, incl. `unverified: bool` (`#[serde(default)]` → `false` for a legacy record): the release's tracks could not be checked.
The point accessors share private `get_json` / `put_json` / `remove_key` helpers (next to `scan_json` / `update_json`).
`remove_trakt_tokens`, `put_wanted`, `remove_wanted`, `get_wanted`, `is_blacklisted`, `remove_authoritative` and `remove_selection` are `#[cfg(test)]`; production removes an account with `remove_trakt_account` and writes a user's rows with `replace_user_wanted_if_enrolled`.
Tests build a fresh store with `Store::in_memory()` over the test-only `from_database` (both `#[cfg(test)]`; production opens through `Store::open`), and the test-only `store::fail_writes` module (`fail_after_arm_store` / `WriteFailSwitch`), shared by every module's tests, builds one whose writes fail from a chosen commit on.
